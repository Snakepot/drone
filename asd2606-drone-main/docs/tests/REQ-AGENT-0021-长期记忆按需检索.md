# REQ-AGENT-0021 端到端回归记录：长期记忆按需检索

- **日期**：2026-10-23
- **环境**：本机；`drone-server` 8080、`drone-mcp-server` 8082、`drone-agent` 8083（独立实例，
  跑完已清理）
- **账号**：admin `13800001005`
- **前置数据**：手工放一份归档会话（模拟历史），内容含
  `任务 TK-2026-1001 的负责人是张伟，设备是 UAV-001`

## 一、停掉无条件注入（AC-1）

> 「现在有多少设备？只回答数量。」

```text
【上下文账单】估算 12649 token
（模板 22 / 系统提示词 2002×1 / 当前会话 13×1 / 工具定义 10612×74）；
模型实际 prompt_tokens=12719，估算偏差 -0.6%
```

- 上下文里**不再出现「长期记忆」分类**（改造前每个请求都带最近 10 轮 / 8000 字符）；
- 工具数从 73 变为 **74**（新增 `search_memory`），工具定义只多约 250 token；
- 对比：注入最多 8000 字符（账单口径约 3–5k token）→ 现在为 0。

## 二、按需检索命中（AC-2）

> 「上次 TK-2026-1001 的负责人是谁？只回答姓名。」

```text
【工具编排】第 1 轮：要调用的工具是「search_memory」，参数={"query": "TK-2026-1001 负责人"}
【记忆检索】命中：userId=5，查询 16 字，归档 1 段，命中 1 段，耗时 5 ms
【工具编排】结果已回填（86 字），进入下一轮
【上下文账单】工具结果分布 {search_memory=1}
```

回复：`张伟`。

- 模型主动调用了检索（提示词 v9 的触发规则生效）；
- 工具结果 86 字，受 2,000 字符上限约束；
- 返回里带会话 `conv=old-001` 与时间 `2026-10-23 09:00`，可供模型注明出处。

## 三、隔离与失败（AC-3 / AC-4 / AC-5）

| 场景 | 结果 |
|---|---|
| 查不存在的任务号 | 返回「没有找到相关记忆」，不编造（单测） |
| 用户 A 的历史 | 用户 B 检索不到（单测，按 userId 分目录） |
| 匿名 / 无 userId | fail-closed：「当前请求没有用户身份」（单测） |
| 参数缺 query | 明确报错（单测） |
| 超长会话 | 摘录前后各 120 字，总长 ≤ 2,000（单测） |

## 四、回滚（AC-6）

`agent.memory.inject-enabled: true` 即恢复「最近 10 轮 / 8000 字符」的无条件注入，
单测 `skipsLongTermWhenInjectionDisabled` 只覆盖关闭路径；开启路径由既有
`ContextAssemblerTest` 的长期记忆用例持续覆盖（测试配置里 `injectEnabled=true`）。
