# REQ-AGENT-0010 内部资料检索 · 端到端回归

> **这是实测记录**：真嵌入 + 真 Milvus + 真模型，不是纸面推演。日期 2026-10-16。
>
> 复现方式：一次性探针（跑完即删，未进提交）——把两份资料放进知识库目录，走
> **入库 → 检索 → 工具 → 模型** 全链路；探针源码见当时的工作区（未保留）。

## 3. 相似度分布（用来定 `min-score`）

| 查询 | 最高分 | 说明 |
|---|---|---|
| 「电池长期存放电量」（相关） | **0.5312** | 命中操作手册「8. 电池与日常保养」 |
| 「火星基地无人机驾照怎么考」（**库里没有**） | **0.4641** | 0 分阈值下**照样返回 5 条**——「查不到」永不发生 |
| 「三者责任险保额建议」+ 无 finance 权限 | 0.3588 | 无权限 → 结果全是操作手册的**低分**块 |
| 「三者责任险保额建议」+ 有 finance 权限 | **0.6155** | 命中保险方案 |

**结论**：**相关 ≈0.53、不相关 ≈0.46**，取 **`min-score: 0.5`** 能把两者分开（0 会让「查不到」永不发生）。
**样本只有 4 条**，属初始值，**应基于更大的评估集再调**。

## 4. 实测发现的问题（以及怎么处理）

1. **`min-score` 默认 0 是错的** → 改成 **0.5**（依据见 §3）。这是**真问题**：不改的话 AC-5 无法成立。
2. **「注明出处」不稳定** → v3 时 2 次里 1 次给；把格式写死（`assistant.system@4`：答复末尾另起一行
   `出处：《文件名 › 章节》`）后，**5 次里 4 次给**。**仍不是 100%**——
   这是模型输出的**固有波动**，没有结构性办法兜底（不像权限那样能在服务端拦住）。
   如实记在这里，**不宣称「必给出处」**。
3. **入库后立刻 `count(*)` 偏小**（29 块只数到 15）→ Milvus 默认 **Bounded 一致性**，
   写完马上查可能没看全。**不影响功能**（检索不受影响），但说明「入库后立刻计数」不可靠。
