## 二、预算规则（AC-2 / AC-3 / AC-4 / AC-5）

| 场景 | 结果 |
|---|---|
| 12.3KB 模板 | 原样返回（单测 `skillTemplateStaysIntact`） |
| 单次 5,000 字符、上限 1,000 | 返回 1,000 以内 + `（技能资料超出预算，已截断…）` |
| 两次各 15,000、累计 20,000 | 第一条完整；第二条只给剩余 5,000 + 截断标记 |
| 累计已用 1,000、上限 1,000 | 第二条返回「预算已用尽」占位，不是空串 |
| 普通业务工具 | 仍走 2,000 / 6,000 预算（既有用例全绿） |
| emoji 截断点 | 回退一位，不产生半个代理对 |

配置（`agent.tool.*`）：

```yaml
max-skill-result-chars: 32768   # 单次，与 skill.max-resource-chars 对齐
max-total-skill-chars: 30000    # 单请求累计
```

## 三、顺带修正账单的 HTML 口径

日报场景下偏差一度到 **−14.5%**：HTML 模板标点密集，套自然语言系数（0.21/字符）会低估。
实测模板 11,300 字符 ≈ 3,969 token，反推非汉字约 **0.34/字符**（与工具定义 JSON 同档）。
`TokenEstimator` 现在按消息类别选口径：工具结果 / 工具调用帧用结构化系数，其余用自然语言系数。

| 场景 | 修正前 | 修正后 |
|---|---|---|
| 日报最后一轮 | −14.5% | **−4.0%** |
| 日报第一轮 | −9.2% | −3.1% |
