# REQ-AGENT-0020 端到端回归记录：会话内压缩

- **日期**：2026-10-23
- **环境**：本机；`drone-server` 8080、`drone-mcp-server` 8082、`drone-agent` 8083（独立实例，
  跑完已清理）
- **账号**：admin `13800001005`

## 一、触发压缩（AC-1）

同一会话连续发 16 轮「记录一条业务信息：任务 TK-2026-10xx 的负责人是张伟，只回复收到」，
每轮追加 user + assistant 两条，第 16 轮前共 31 条：

```text
【上下文压缩】完成：userId=5，conversationId=compact-smoke2，
摘要 21 条消息（下标 0..21），摘要 788 字，保留最近 10 条
```

- 触发点 30 条、保留 10 条，与配置一致；
- **只触发一次**：后续轮次未重复摘要（未摘要条数回落到 10）。

## 二、摘要可用性（AC-1）

压缩后追问：

> 「这个会话最开始，我让你记录的第一条业务信息是什么？请按原话概括」

回复：

```text
会话最开始那条要求是：记录「任务 TK-2026-1001 的负责人是张伟」，并要求我只回复「收到」。
```

这条信息位于被摘要的前 21 条里，说明摘要确实进入了上下文且保留了关键事实。

## 三、账单（AC-5）

```text
【上下文账单】… 当前会话 555×11 / 历史摘要 370×1 / 工具定义 10516×73；
模型实际 prompt_tokens=13599，估算偏差 -2.2%
```

- 新增 `历史摘要` 分类，token 计入合计；
- 压缩后上下文体量稳定在「最近 10 条 + 摘要」，不再随轮数线性增长。

## 四、边界与失败（AC-3 / AC-4 / AC-6）

| 场景 | 结果 |
|---|---|
| 未达阈值（20 条） | 不调用摘要，行为与改造前一致（单测） |
| 摘要模型不可用 | 回退「最近 20 条」，请求照常成功（单测） |
| 摘要超长 | 注入前硬截断到 1,500 字并带省略号（单测） |
| 摘要为空 | 不推进游标，下轮可重试（单测） |
| 摘要段全是非白名单角色 | 不调模型，直接推进游标（单测） |

- 未做子代理 / 分段摘要树。
