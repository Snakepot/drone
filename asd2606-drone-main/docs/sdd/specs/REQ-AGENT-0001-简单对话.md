## 1. 背景与目标

管理端用户在处置设备、任务、告警时，会遇到「这条告警怎么处理」「这个执行报告怎么看」这类问题，
过去只能靠翻文档或问同事。目标是在平台内提供一个对话入口，就地提问、就地得到答复，
不必跳到平台之外。

## 2. 范围

### 做（In Scope）

- 管理端顶栏提供「智能助手」入口，点击在屏幕右侧展开对话面板
- 单轮问答：发送一句提问，得到一段回复
- 流式输出：回复逐段显示，不必等全文
- 面板支持全屏（正文限宽居中）
- 回复范围约束：只答无人机业务相关问题，无关问题委婉拒绝
- 模型调用留痕：入参/出参全量日志

### 不做（Out of Scope）

- 不保存会话到服务端（服务保持无状态；历史由前端持有，见 `REQ-AGENT-0002`）
- 不做多模态（图片、语音）
- 不做小程序端入口（本次只做管理端）
- 不做知识库检索（RAG），模型只凭自身知识与系统提示词作答
- 不做多模型切换、不做按用户配额

> 说明：「流式输出」「全屏」是分两次增量交付的。按 SDD 应各自立一个需求，
> 此处按现状合并记录；**后续新增的对话能力请单独开 REQ**，不要再往本文件里塞。

## 3. 验收条件

| 编号 | 前置（Given） | 操作（When） | 预期（Then） |
|---|---|---|---|
| AC-1 | 未携带 Token | 调用 `/chat` 或 `/chat/stream` | 返回 401，响应体为统一 JSON，**不是** SSE |
| AC-2 | 持有效 Token 但无 `agent:chat` 权限 | 同上 | 返回 403 |
| AC-3 | 持有效 Token 且有 `agent:chat` | 调用 `/chat` | 返回 200，`data.reply` 为回复正文 |
| AC-4 | 当前账号无 `agent:chat` 权限 | 登录后查看顶栏 | 看不到「智能助手」入口 |
| AC-5 | 已登录且有权限 | 调用 `/chat/stream` | 响应 `Content-Type: text/event-stream`，逐块收到 `data:{"delta":"..."}`，最后一帧后流结束 |
| AC-6 | 模型侧中途失败（如未配置 API-KEY） | 调用 `/chat/stream` | 收到 `data:{"error":"..."}` 事件，流正常收束，连接不悬挂 |
| AC-7 | 流式进行中客户端断开 | 关闭面板或刷新页面 | 服务端停止读取模型流，不再继续转发 |
| AC-8 | 已登录且有权限 | 提问「帮我写一首诗」「翻译成英文」「写个 Python 脚本」 | 委婉拒绝，且**不解释**所问之事是什么、不解释为何不属于业务范围 |
| AC-9 | 同上 | 提问「飞行前要不要看天气」这类**字面无「无人机」但属业务**的问题 | 正常作答，不得误杀 |
| AC-10 | 同上 | 查看服务端日志 | 模型入参（完整请求体）与出参均被记录；日志中**不含** API-KEY |
| AC-11 | 面板处于抽屉态 / 窗口宽度 ≤ 640px | 点击全屏 / 打开面板 | 全屏后铺满窗口、正文限宽居中；窄屏抽屉占满宽度 |
| AC-12 | 已登录且有权限 | 请求里传 `systemPrompt` 字段 | 不生效（该字段已从契约中移除），人设只由服务端配置决定 |

### 非功能要求

- **性能**：面板开合不得阻塞主界面；流式输出须在首段到达时立即渲染（不等全文）。
- **安全**：入口与接口双重按 `agent:chat` 收口；日志不得出现密钥；`/internal/**` 不得暴露到网关外。
- **兼容性**：`drone-web` 全屏与窄屏两种形态均可用。

## 4. 约束与依赖

- 依赖 `drone-server` 的 JWT 与 RBAC：`drone-agent` 无独立登录，验签 + 调
  `GET /internal/user/{id}/authorities` 取权限（60 秒缓存）。
- 依赖环境变量 `DEEPSEEK_API_KEY`；未配置时服务仍能启动，`/chat` 返回提示。
- 依赖数据库迁移 `drone-server/docs/sql/migration/agent_permission.sql`
  新增权限码 `agent:chat` 并授予 `admin`。
- 依赖前端代理：`drone-web/vite.config.ts` 中 `/api/agent` 必须排在 `/api` 之前。
