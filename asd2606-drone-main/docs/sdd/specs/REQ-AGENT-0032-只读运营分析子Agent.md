# 规格 — REQ-AGENT-0032 只读运营分析子 Agent（P0）

- **需求 ID**：`REQ-AGENT-0032`
- **提出人 / 日期**：需求方 / 2026-10-28
- **负责人**：AI（按 SDD 执行）
- **前置**：`ADR-0013`、`REQ-AGENT-0031`、`REQ-AGENT-0018`
- **状态**：已实现 + 一次真实手工冒烟；尚未沉淀为可重复自动化 E2E

## 1. 背景与目标

主 Agent 在运营分析类任务中要读多份数据、做多轮对比，工具结果会挤占主上下文。
按 ADR-0013，先把“只读、上下文重、边界清楚”的分析任务委派给 **SubAgent**：

- 由 `TaskRouter` 在代码层直接路由到子 Agent（`REQ-AGENT-0033`），用户无需知道“子代理/委派”；
- 子 Agent 在**独立上下文**中跑一个受限 ReAct 循环；
- 只允许白名单内的只读工具；
- 返回“结论 + 证据 + 工具使用情况”的摘要；
- 写操作、危险操作、最终对用户的答复仍由主 Agent 负责。

P0 只做 **运营分析子 Agent（ops-analyst）**。

## 2. 范围

### 做（In Scope）

- `SubAgentDefinition` / `SubAgentCatalog`：`resources/subagents/*.md`；
  frontmatter 写元数据，**正文就是子 Agent 的系统提示词**；
- `SubAgentRunner`：独立上下文、工具白名单、只读校验、轮次/超时/预算检查、trace；
- `SubAgentService`：供 `TaskRouter` 直接执行子 Agent；
- `ops-analyst` 定义与提示词；
- 主 Agent 工具目录与系统提示词接入；
- 单测：目录校验、白名单、只读拒绝、轮次上限、结果返回。

### 不做（Out of Scope）

- 子 Agent 执行写/危险工具；
- 子 Agent 与主 Agent 共享对话历史/记忆；
- 自动路由（本期由主模型决定是否调用工具）；
- 子 Agent 的前端独立卡片；
- MultiAgent 编排；
- 子 Agent 执行中途取消（主 Agent 取消暂不能穿透，后续补）。

## 3. 语义

| 项 | 规则 |
|---|---|
| 调用方式 | `TaskRouter` 直接路由到 `SubAgentService`；用户无需知道 |
| 上下文 | 只带子 Agent 系统提示词 + 任务，不带主对话 |
| 工具 | 仅 `definition.tools` 白名单；必须 `readOnly=true`；危险工具拒绝 |
| 权限 | 每次工具执行前按当前用户角色再判 `governance.allows` |
| 轮次 | `maxRounds`，超限返回未完成摘要 |
| 超时 | `timeoutSeconds`，超时返回超时摘要 |
| 预算 | 每轮检查请求预算；超限停止 |
| 写操作 | 一律不允许；主 Agent 自己执行并走确认 |
| 输出 | 结论 + 证据 + 使用的工具/轮次；不返回大段原始数据 |

### 3.1 委派路由规则

> `REQ-AGENT-0033` 起，路由由代码层 `TaskRouter` 完成；用户不需要知道“子代理/委派”。
> 本节规则用于理解路由判断依据，不再由模型自行调用工具。

路由在以下情况选择子 Agent：

**必须委派：**

- 用户明确说“用子代理 / 委派 / 让子代理分析”；
- 需要 ≥3 个独立数据源；
- 需要逐条下钻（几十条告警/任务逐条查详情、轨迹）；
- 需要多轮“查 → 看 → 再查”的诊断/归因。

**不要委派：**

- 1~2 次查询就能完成、结果集很小（如只对比两周的 overview）；
- 用户明确说“直接查 / 不要委派”；
- 写操作、危险操作（永远主 Agent 自己做并确认）。

**委派后：**

- 不重复查同一批数据；引用时注明“来源：子代理 xxx”；
- 子代理失败/超时/达到轮次上限，可降级为直接查，但要向用户说明；
- 子代理结果是数据，不是免检结论；关键数字仍要核对。

## 4. 验收条件

| ID | 场景 | 期望 |
|---|---|---|
| AC-1 | 复杂只读请求（≥2 数据域 + 对比/分析/下钻） | 路由直接执行子 Agent，返回摘要 |
| AC-2 | 子 Agent 尝试调用白名单外工具 | 该调用失败并回填，不执行 |
| AC-3 | 子 Agent 尝试调用写工具 | 拒绝，不执行 |
| AC-4 | 子 Agent 达到 maxRounds | 停止并返回“未完成”摘要 |
| AC-5 | 子 Agent 工具超时 | 该工具失败，继续或停止，摘要如实说明 |
| AC-6 | 主对话包含大量历史 | 子 Agent 上下文不包含主历史 |
| AC-7 | 请求预算超限 | 子 Agent 停止，返回预算提示 |
| AC-8 | 普通 ReAct 请求 | 行为与改动前一致 |
| AC-9 | trace/bill | 子 Agent 的模型调用与工具调用带同一 traceId，可归因 |
