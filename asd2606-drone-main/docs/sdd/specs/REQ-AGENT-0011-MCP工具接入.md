# 规格 — REQ-AGENT-0011 智能助手通过 MCP 调用高德 MCP Server

> 本文件只回答**做什么、达到什么效果**。不写实现方案（那是 `plans/` 的事）。

- **需求 ID**：`REQ-AGENT-0011`
- **提出人 / 日期**：需求方 / 2026-10-21
- **负责人**：AI（按 SDD 执行）

## 1. 背景与目标

`drone-agent` 目前的工具是「自研 `Tool` + 配置文件静态元数据」，唯一的实时数据工具
`get_flight_weather` 直接调 Open-Meteo，能力单一、换数据源要改代码。

需求方希望助手能通过 **MCP（Model Context Protocol）** 调用**高德 MCP Server**，
获得天气、地理编码、POI 检索、路径规划、打车唤端等能力；并要求：

1. 架构**可扩展**：以后接新的 MCP Server 只加配置、不改代码；
2. 下线 `get_flight_weather`；
3. 日志与注释能让人**读懂一次 MCP 调用的完整流程**；
4. 配套一份面向初级工程师的接入手册。

## 2. 范围

### 做（In Scope）

- 新增 MCP 客户端（Streamable HTTP，兼容 2025-03-26 生命周期）。
- 启动时发现远程工具，按 `别名__工具名` 合并进现有工具注册表。
- 支持多 MCP Server 配置（列表），默认接入高德；白名单机制保留，默认留空即暴露全部工具（需求方 2026-10-21 确认）。
- 删除 `get_flight_weather` 及其 Open-Meteo 实现、配置与测试。
- 更新系统提示词（v5）：说明高德工具用法与边界。
- 全流程日志（发现、调用、失败）与脱敏。
- SDD 三件套、ADR-0007、接入手册。

### 不做（Out of Scope）

- MCP 的 `resources` / `prompts` / `sampling` / `roots` 能力，只做 `tools`。
- OAuth 授权流程；本期只用「URL 里带 key」或静态请求头。
- stdio 传输与本地子进程 MCP Server（保留扩展接口，本期不实现）。
- 多实例会话一致性（与 ADR-0003 同一议题）。
- 让模型直接触发高德 App 内的下单/支付动作；唤端链接只作为结果返回。

## 3. 验收条件

| 编号 | 前置（Given） | 操作（When） | 预期（Then） |
|---|---|---|---|
| AC-1 | 已配置 `AMAP_MCP_KEY`，高德可达 | 启动服务 | 启动日志含「发现 N 个工具」；注册表含 `amap__maps_weather` |
| AC-2 | 服务已按 AC-1 启动 | 提问「北京明天天气怎么样」 | 模型调用 `amap__maps_weather`，回填真实天气，最终答复含温度数值 |
| AC-3 | 未配置 `AMAP_MCP_KEY` | 启动服务 | 启动不失败；WARN 说明该服务器被跳过；普通对话仍可用 |
| AC-4 | 高德不可达，`fail-fast=false` | 启动服务 | 启动在 `startup-budget` 内完成；WARN；本地工具（`search_knowledge`）仍可用 |
| AC-5 | 远程工具返回 `isError=true` | 模型调用该工具 | 编排层收到 `ok=false` 与错误文本，模型据此向用户说明失败 |
| AC-6 | 一次成功调用发生 | 查看日志 | 能按顺序读出：发现 → 请求 → HTTP 状态/耗时 → 回填长度 → 答复，且标明执行线程 |
| AC-7 | — | 全仓搜索 `get_flight_weather` | 代码、配置、提示词中均无残留（历史 SDD 文档除外） |
| AC-8 | 已有高德服务器运行中 | 在配置里新增第二个 MCP Server | 无需改代码即可发现并注册其工具；工具名带各自别名前缀 |
| AC-9 | 配置中含密钥的 URL | 触发任何日志与异常 | 日志中 `key=` 后的值被脱敏，不出现明文密钥 |

### 非功能要求

- 启动：MCP 发现总预算 `startup-budget` 默认 8s，超时即降级。
- 调用：单次 MCP 请求超时默认 8s，必须小于编排层 `invoke-timeout`（15s）。
- 容量：本期按 1–2 个 MCP Server、每服务器 ≤ 20 个工具估算。
- 安全：密钥只从环境变量注入；日志与异常消息脱敏；远程工具默认只读、不参与危险工具确认。
- 兼容性：高德实际协议版本为 2025-03-26；客户端需兼容；对 2026-07-28 的无状态服务器不得报错。

## 4. 约束与依赖

- 依赖：高德 MCP Server（`https://mcp.amap.com/mcp`）与其 Web 服务 Key。
- 外部约束：MCP 规范当前为 2026-07-28，但高德尚未升级，客户端以老版本生命周期为准。
- 内部约束：`ToolRegistry` 要求「行为 ↔ 元数据」1:1，MCP 工具必须在启动期成对注册。
