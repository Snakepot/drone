## 1. 背景与目标

现在的工具**一被模型请求就自动执行**，既没有权限门，也没有确认门。
对「查天气」这类只读工具没问题；但将来会有**不可逆**的工具，例如
**删除设备、删除飞手、解散任务、下发指令**。这些一旦被模型误判、或被
「能聊天但不能删数据的人」诱导触发，后果不可逆。

目标：给工具加三道门，**写/危险类工具必须：① 有对应权限码的人 ② 本人在前端二次确认 ③ 执行留审计**；
只读工具不受影响。

## 2. 范围

### 做（In Scope）

- **角色 ↔ 工具 的授权由配置文件维护**：配置里声明「哪些角色可以用哪些工具」；
  执行前用当前登录人的**角色**比对（角色来自现有 RBAC：`AuthoritiesClient` + `UserContext`）
- **权限不足 → 不执行**：回填「无权限」，让模型如实告知用户；**绝不提权执行**
- **危险工具清单由配置文件维护**：名单内的工具执行前**每次都**要走人工确认
- **人工二次确认**：命中清单的工具**不立即执行**，先返回「待确认 + 动作摘要」；
  用户在前端确认后，经**新增的 `/chat/confirm`** 执行，并把结果继续喂给模型
- **`/chat` 出参扩展**：新增**可选**字段 `pending`（含 `pendingId` 与动作摘要），供前端弹确认框；
  **向后兼容**——老客户端忽略它，只是看不到确认入口
- **只读工具不受影响**：不进确认流程，行为与现在一致
- **审计**：危险工具每次执行落一条审计（谁 / 哪个工具 / 参数摘要 / 结果 / 时间）

### 不做（Out of Scope）

- **不做行级 / 数据级权限**：本期只到**角色粒度**（不判「这个飞手归不归你管」）
- **不做多级审批流**：本期只「本人当场二次确认」，不做「提交给上级审批」
- **不做「确认时填写操作原因」**（Q-5 结论：不需要）
- **不做危险操作的自动回滚 / 事务补偿**
- **不做工具结果的可信度评估**（模型是否该调用，仍由模型判断）

## 3. 验收条件

| 编号 | 前置（Given） | 操作（When） | 预期（Then） |
|---|---|---|---|
| AC-1 | 当前用户的**角色**不在配置允许名单内 | 让助手删除某设备 | 工具**不被执行**；返回「无权限」，模型如实告知；**不泄露**被删对象详情 |
| AC-2 | 当前用户**在允许名单内** | 让助手删除某设备 | 服务端**不立即执行**，返回「待确认 + 动作摘要（删哪个设备）」 |
| AC-3 | 已返回待确认动作 | 用户在前端**确认** | 执行该动作，结果回填，模型给出最终答复 |
| AC-4 | 已返回待确认动作，**超过有效期** | 用户才确认 | **拒绝执行**（动作已过期），提示需重新发起 |
| AC-5 | 同一个待确认动作 | **重复**提交确认 | **只执行一次**（幂等），不产生第二次副作用 |
| AC-6 | 任一次危险工具执行 | 查看审计 | 有一条审计：`userId`、工具名、参数摘要、结果、时间 |
| AC-7 | 只读工具（查天气） | 使用助手 | 行为**与现在一致**（不确认、不额外提示） |
| AC-8 | 危险工具调用 | 查看日志 | 不含 API Key / `Authorization`；参数按脱敏规则处理 |
| AC-9 | 用户刚确认过一次同类操作 | **再次**让助手做同类危险操作 | **仍要**确认（不会因为刚确认过而跳过）——Q-6 结论：每次都确认 |

### 非功能要求

- 性能：确认动作的存取开销可忽略；不做量化要求
- 容量：待确认动作数量有上限、有有效期（默认值见 Q-1）
- 安全：**权限判定在服务端**；前端隐藏按钮只是体验，不构成边界；确认动作需**防重放、防越权**
  （只能本人确认自己发起的动作）
- 兼容：只读工具行为**不变**；`/chat` 出参**新增可选字段** `pending`（向后兼容，老客户端忽略）

## 4. 约束与依赖

- 依赖 `drone-server` 的 RBAC：新增所需**权限码**（如 `device:delete`、`user:delete`）需在
  `drone-server` 侧登记并授予相应角色（飞手不得拥有）
- 引入服务端**短期有状态**（待确认动作）→ 见 `ADR-0005`；与 `ADR-0003`「单实例」前提一致
- 前端需新增**确认交互**（弹窗/二次提交）
- 与 `REQ-AGENT-0005` 共用「工具元数据」（有无副作用），见该需求 Q-1
