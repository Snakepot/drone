# 规格 — REQ-AGENT-0016 流式输出与思考过程展示

- **需求 ID**：`REQ-AGENT-0016`
- **提出人 / 日期**：需求方 / 2026-10-22
- **负责人**：AI（按 SDD 执行）

## 1. 背景与目标

聊天面板目前用非流式接口，等整段生成完才显示，且模型的 `reasoning_content` 完全不可见。
目标：

1. **流式输出**：回复逐字出现，不等整段；
2. **思考过程**：展示 reasoning，并显示用时；可折叠（参考 DeepSeek 的交互）。

## 2. 范围

### 做（In Scope）

- 模型调用支持流式 `content` / `reasoning_content` / `tool_calls` 分片。
- 工具循环改为流式：每轮增量实时推送，工具执行期间推送状态。
- SSE 事件协议：`reasoning` / `content` / `status` / `done` / `error`。
- 前端思考块（折叠 / 用时）、流式正文、状态行。
- **思考过程使用中文**：reasoning 会展开给用户看，不能是英文（提示词规则，系统提示词 v8）。
- 危险操作暂停、HTML 产物在流式路径下仍然生效。

### 不做（Out of Scope）

- 不做 Markdown 渲染；思考与正文仍为纯文本。
- 不做思考过程入库/回放（刷新即消失）。
- 不改 `/chat` 与 `/chat/confirm`（确认流程仍非流式）。

## 3. 验收条件

| 编号 | 前置 | 操作 | 预期 |
|---|---|---|---|
| AC-1 | 已登录、`agent:chat` | 问一个需要工具的问题 | 正文**逐段**出现，而非整段一次性出现 |
| AC-2 | 模型返回 reasoning | 同上 | 正文前展示思考过程；正文开始后自动折叠 |
| AC-3 | 同上 | 观察折叠标题 | 显示「已深度思考（用时 N 秒）」；N 为该轮请求到首个正文增量的秒数（±1s） |
| AC-4 | 需要调用工具 | 同上 | 工具执行期间显示「正在查询…」状态；正文开始后隐藏 |
| AC-5 | 命中危险工具 | 同上 | 仍返回 `pending`，前端弹确认框；确认后走原流程 |
| AC-6 | 回复含 HTML 产物 | 同上 | `done` 带 `artifacts`，卡片可预览/下载 |
| AC-7 | 用户中途关闭面板 | 同上 | 后端停止读取模型流，不继续消耗额度 |
| AC-8 | 一次流式对话结束 | 查看会话 | 持久化的是完整回复（不含 reasoning、不含 HTML 源码） |
| AC-9 | 模型返回 reasoning | 展开思考块 | 思考内容为**中文**；专有名词、工具名可保留原文 |

### 非功能要求

- 首字延迟不因改造而增加（同一模型、同一请求参数）。
- 事件类型固定 5 种；非法/未知类型前端忽略并记 debug。
- 流式中断时，前端保留已生成内容并给出错误提示。

## 4. 约束与依赖

- 取代 `ADR-0004` 的「工具只走非流式」结论（ADR-0011）。
