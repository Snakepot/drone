# ADR-0006 内部资料检索能力内聚于 drone-agent，向量库采用自托管 Milvus

- **状态**：提议（待评审）
- **日期**：2026-10-16
- **决策人**：项目负责人（待确认）
- **记录人**：AI（按规范登记）
- **关联**：[ADR-0003](./ADR-0003-引入记忆与服务端有状态.md)、[`specs/REQ-AGENT-0010-内部资料检索.md`](../specs/REQ-AGENT-0010-内部资料检索.md)

## 背景

要让助手能用**自然语言检索内部资料**（先落地《无人机操作手册》《无人机保险方案》，可扩到任意目录）。
需求方明确了三件事：**资料多、格式杂**；**后续上向量模型**；**按角色（复用平台 RBAC）控权**。
并强调「**要企业级架子，不为临时效果做 demo**」。

落地前有四个必须先定、且影响架构的约束：

1. **能力放哪**：单列服务，还是内聚进 `drone-agent`？
2. **数据存哪**：宪法 §2 规定 **`drone-agent` 不得访问 `drone-server` 的数据库**；
   而 `drone-agent` 现状是「内存 + 本地文件」，**没有**自己的库。
3. **向量库选型**：引入哪种向量存储，是否引入额外中间件。
4. **可测性**：宪法 §5 规定单测**不得依赖真实外部环境**（真库/真中间件），向量库不能在单测里真连。

## 决策

### 1. **不新增独立服务**，检索能力内聚进 `drone-agent`

- 作为 `drone-agent` 内部的模块（包 `cn.tedu.droneagent.kb`），复用既有的工具框架、提示词、追踪、脱敏与线程池。
- **代价**（如实登记）：`drone-agent` 变得更重；且它本已**有状态**（见 `ADR-0003`），本决策**把有状态范围扩大到向量库**，
  **单实例前提不变**（多实例需另行处理，与 `ADR-0003` 同一议题）。

### 2. **向量与块存储采用自托管 Milvus**，不新建关系库

- Milvus 同时承担：**块文本 + 向量 + 标量字段（来源/章节/权限码）**，并支持**标量过滤**。
- **不引 MySQL / 不碰 drone-server 的库**：宪法 §2 禁止；另起一个库又会引入第二套数据中间件。
  文档台账（原始文件、版本、哈希）放 `data/knowledge/` 目录，与记忆子系统的「文件 + 台账」同思路。
- Milvus 以 **Docker 部署**（单机 standalone 即可满足当前规模），**属新增中间件**，故记本 ADR。

### 3. **四个变化点全部接口化**：`DocumentParser` / `EmbeddingModel` / `Retriever` / `VectorStore`

- **为什么**：宪法 §5 要求单测可离线运行 → 单测用**内存实现**（如 `InMemoryVectorStore`），
  **Milvus 实现归集成测试**并单独标记；同时让「换嵌入模型 / 换检索算法 / 加格式」**不动上层**。
- **多格式解析**：保留 `DocumentParser` 接口，**当前只实现 Markdown**（避免一开始就引重型解析依赖）。

### 4. **权限复用 drone-server 的 RBAC**，资料按**权限码**打标，且**前置过滤**

- 需求方定（2026-10-16）：**按权限码**（而非角色名）声明资料可见范围。
- 文档/块携带**可见权限码**标签；检索时用**当前登录人的权限码**构造**标量过滤条件**下发到 Milvus，
  **无权内容在检索阶段就不参与**（不靠模型「别说」）。判定仍在服务端（宪法 §4）。

### 5. **嵌入走 embedding API**（供应商 / 模型名配置化）

- 需求方定（2026-10-16）：语义向量**由 embedding API 生成**。——`EmbeddingModel` 的 API 实现，
  供应商 / 模型名 / base-url **走配置**，api-key **从环境变量读**（宪法 §4：真实值不进仓库）。
- **本地模型后续再议**，本期不做。
- 单测**不真调 API**（宪法 §5）：用**桩**；API 实现归**集成测试**。

## 后果

- 助手具备「检索内部资料并注明出处」的能力，且**权限、注入防护、可回退**沿用既有机制。
- 新增：Milvus（Docker）、Milvus SDK 依赖、`data/knowledge/` 目录；部署文档需补。
- `drone-agent` 有状态范围扩大，**仍为单实例**（与 `ADR-0003` 一致）。
