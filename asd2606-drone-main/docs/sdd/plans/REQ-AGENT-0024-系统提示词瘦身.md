# 技术方案 — REQ-AGENT-0024 系统提示词瘦身

- **需求 ID**：`REQ-AGENT-0024`
- **前置**：`REQ-AGENT-0008` / `REQ-AGENT-0023`

## 1. 方案概述

只改一个文件：`prompts/assistant/system.md`（v9 → v10）。

| 原小节 | 处理 |
|---|---|
| 业务范围（10 条列表） | 压成 3 行，保留判断标准与一个边界示例 |
| 怎么判断业务问题（5 个示例） | 合并到业务范围，只留「适合起飞 / 出门带伞」一组对照 |
| 高德地图工具（逐工具说明） | 删除工具名清单，保留 4 条跨工具规则（先查、坐标、路线、唤端） |
| 平台业务工具 | 与地图合并为「工具使用总则」7 条，删除重复的权限/分页描述 |
| Skill | 保留 5 条规则，合并「并发调用」「DSML」到一行 |
| 历史记忆 | 保留触发条件与 3 条使用规则 |
| 内部资料 | 保留「先检索 / 只依据原文 / 出处格式 / 照要点答」 |
| 数据与指令 | 合并进工具总则（信封是数据） |
| 怎么拒绝（6 条 + 反例） | 压成 3 行，保留示例语气，删除长反例 |
| 其他 | 保留语言、保密、简洁、抗越狱 4 条 |

## 2. 影响面

| 维度 | 影响 | 说明 |
|---|---|---|
| 接口 | 无 | 只改提示词内容 |
| 上下文 | 系统提示词约减半 | 模板部分 1,844 → 848（估算） |
| 缓存 | 指纹变化一次 | 新提示词上线后需重新预热 |
| 行为 | 不变（需评估验证） | 规则语义保留，只删重复与示例 |

## 3. 关键设计决策

| 决策点 | 备选 | 结论 | 理由 |
|---|---|---|---|
| 工具名清单 | 保留 / 删除 | **删除** | 工具定义里已有名称、描述、参数；提示词重复一遍只占预算 |
| 拒答反例 | 保留整段 / 压缩 | **压缩** | 规则本身一句话能说清；反例是教学材料，不该常驻 |
| 业务范围 | 10 条列表 / 一段话 | **一段话** | 模型只需知道边界，不需要逐项枚举 |
| 是否拆多份提示词 | 拆 / 不拆 | **不拆** | 当前只有一个场景；拆分会把「加载与拼装」复杂化 |

## 4. 验证方法

1. `PromptCatalog` 单测：frontmatter、变量、占位符合法；
2. 账单对比：系统提示词 token（改造前后）；
3. 评估集：`REQ-AGENT-0023` 的 9 条用例，通过率、上下文 token、延迟、缓存命中；
4. 关键行为抽查：拒答、知识出处、记忆检索、Skill 触发。

## 5. 风险与回滚

| 风险 | 触发 | 影响 | 应对 |
|---|---|---|---|
| 删得太多导致行为漂移 | 规则被合并丢失 | 工具调用/拒答异常 | 评估集 9 条全跑；不通过则补回对应规则 |
| 缓存命中短期下降 | 提示词变化 | 首轮成本上升 | 预期现象，预热后恢复 |
| 工具名记不住 | 删除了清单 | 调错工具 | 工具定义含名称与描述；评估集工具命中验证 |
| 回滚 | — | — | 用 git 恢复 v9 文件并重启 |
