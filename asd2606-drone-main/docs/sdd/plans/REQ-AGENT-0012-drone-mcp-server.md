# 技术方案 — REQ-AGENT-0012 新建 drone-mcp-server，把现有业务接口暴露为 MCP 工具

> 输入是 `specs/REQ-AGENT-0012-drone-mcp-server.md`。

- **需求 ID**：`REQ-AGENT-0012`
- **作者 / 日期**：AI / 2026-10-21
- **评审人 / 评审日期**：需求方 / 2026-10-21（方案已确认）

## 1. 方案概述

新增独立工程 `drone-mcp-server`：从**构建期提交的 OpenAPI 快照**生成 70 个工具目录，
以手写 JSON-RPC 提供 `tools/list` / `tools/call`；调用时把用户 JWT 原样转发给 `drone-server`
的公开业务接口，由它做鉴权与业务处理。`drone-agent` 侧把请求线程上的 token 显式传入
`ToolContext`，并为该 MCP 服务器开启`forward-authorization`。

## 2. 影响面

| 维度 | 影响 | 说明 |
|---|---|---|
| 接口 | 新增（内部） | `POST /mcp`（JSON-RPC）、`GET /health`；不对公网暴露 |
| 数据模型 | 无 | 不落库 |
| 兼容性 | 兼容 | 新增服务；agent 配置新增一条 server；不改变既有工具行为 |
| 性能 | 有 | agent 每轮多约 70 个工具定义（≈15k tokens）；每次调用多一跳 |
| 其他服务 | 影响 `drone-server` 的调用量 | 只调公开接口，不改代码 |

## 3. 接口清单

| 方法 | 路径 | 入参 | 出参 | 鉴权 |
|---|---|---|---|---|
| POST | `/mcp` | JSON-RPC 2.0 | JSON-RPC 2.0（或 202 空体） | `tools/call` 必须带 `Authorization` |
| GET | `/health` | — | `{"status":"UP","tools":70}` | 无（仅回环） |

## 4. 数据模型变更

- 无。工具目录在内存中，由快照生成；快照文件提交在仓库。

## 5. 关键设计决策

| 决策点 | 备选 | 结论 | 理由 |
|---|---|---|---|
| 工具定义来源 | 手写 / 启动拉取 / 构建期快照 | **构建期快照 + 可选后台刷新** | 手写必然漂移；启动拉取造成启动顺序依赖 |
| 身份 | 服务账号 / 用户 JWT | **用户 JWT** | 权限与审计落到真人 |
| 实现 | Spring AI MCP starter / 手写 | **手写** | 只需 4 个方法；与客户端一致；避免新 BOM |
| 工具可见性 | 按权限裁剪 / 全局 | **全局** | 注册表启动期固定；越权由下游 403 兜底 |
| 重试 | 全量重试 / 不重试 | **保持编排层一次重试，用超时分层压低窗口** | 不改既有编排语义 |

## 7. 风险与回滚

| 风险 | 触发 | 影响 | 应对 |
|---|---|---|---|
| 快照过期 | 改接口忘同步 | 工具参数不符 | 后台刷新打印差异；脚本纳入提交清单 |
| 写操作重复执行 | 超时后重试 | 重复派发 | 超时分层 + 危险确认；残留风险记录 |
| 70 工具 token 成本 | 默认全开 | 成本/准确率 | `include` 可收窄 |
| 第五工程合规 | 宪法 §2 | 架构偏离 | ADR-0008 |

- 上线方式：新增服务，agent 配置加一条 server 即可；可单独关闭。
- 回滚：从 agent 配置删除 `drone` server 并重启；`drone-mcp-server` 可停机，不影响其他功能。
- 数据修复：无。

## 8. 与项目宪法的一致性

- §2「四个工程 / 服务间只走 `/internal/**`」**字面冲突**，已用 ADR-0008 记录偏离与理由，需负责人批准。
- §3 统一响应体：MCP 服务只做转换，不改 `JsonResult` 语义。
- §4 安全：JWT 不落日志、默认回环绑定；越权由服务端判定。
- §5 测试：单测使用快照与 `HttpServer` 桩，不依赖真实 8080。
- §7 配置：上游地址、超时、刷新策略全部外置。
