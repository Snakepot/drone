# 技术方案 — REQ-AGENT-0014 业务流程 Skill

> 输入是 `specs/REQ-AGENT-0014-业务流程Skill.md`。

- **需求 ID**：`REQ-AGENT-0014`
- **作者 / 日期**：AI / 2026-10-22
- **评审人 / 评审日期**：需求方 / 2026-10-22（已确认按权限裁剪）

## 1. 方案概述

新增 `cn.tedu.droneagent.skill` 包：启动扫描 `classpath*:skills/*/SKILL.md`，只解析 frontmatter 建 L1；
模型按需调用 `use_skill` 取正文（L2）、`read_skill_resource` 取参考资料（L3）。
L1 按当前用户权限实时过滤后写进系统提示词，权限通过 `ToolContext` 显式传到 `ChatService`。
首期随包提供四条业务 SOP。

## 2. 影响面

| 维度 | 影响 | 说明 |
|---|---|---|
| 接口 | 无 | 不新增对外 HTTP 接口 |
| 数据模型 | 无 | Skill 是只读文件资产 |
| 兼容性 | 兼容 | 无权限用户看到的提示词与旧版一致（只是多了「暂无」一行） |
| 性能 | 有（正向） | L1 按权限裁剪；L2/L3 按需加载 |
| 其他服务 | 无 | 只编排现有 MCP 工具 |

## 3. 接口清单

无新增对外接口。内部新增两个工具（写进 `agent.tool.catalog`）：

| 工具 | 入参 | 出参 |
|---|---|---|
| `use_skill` | `{name}` | 正文 + 资源清单 + 执行约束 |
| `read_skill_resource` | `{skill, path}` | 资源原文 |

## 4. 数据模型变更

无。

## 5. 关键设计决策

| 决策点 | 备选 | 结论 | 理由 |
|---|---|---|---|
| 执行方式 | 工作流引擎 / 指令式 | **指令式** | 模型已有工具循环；引擎会重复造编排层，且难以处理动态条件（ADR-0009） |
| 可见性 | 全局 / 按权限 | **按权限（全部具备）** | 省 token，避免把用不了的流程摆给模型 |
| 存放 | classpath / 外部目录 | **classpath** | 与 prompts 一致，随代码评审与回滚 |
| 校验 | 宽松 / 严格 | **严格**：缺权限/正文/重名即启动失败 | 资产化要求可追溯，坏文件不能静默上线 |

## 7. 风险与回滚

| 风险 | 触发 | 影响 | 应对 |
|---|---|---|---|
| 模型跳步 | 指令未被遵守 | 报表口径不一致 | 正文强制「按序执行、缺一步停下」；冒烟核对 |
| 权限漂移 | 改了 skill 的 permissions | 用户看不到/看到不该看的 | 启动校验非空；调用二次校验 |
| 正文过长 | 写得太细 | 上下文膨胀 | 细节放 references；正文上限 3000 字 |

- 回滚：`agent.skill.enabled=false` 或删除 `skills/` 目录；不影响其他能力。
- 数据修复：无。
